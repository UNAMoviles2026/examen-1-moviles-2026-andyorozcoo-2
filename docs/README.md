# Coworking Spaces App

## Descripción del proyecto

Este proyecto corresponde a una aplicación móvil para usuarios que necesiten encontrar y explorar espacios de coworking para trabajar.

La aplicación permite visualizar espacios disponibles, consultar información detallada y simular una reservación.

## Tecnologías utilizadas

- Kotlin
- Jetpack Compose
- Android Studio
- Mock data

## Arquitectura

El frontend utiliza el patrón MVVM para separar la interfaz de usuario de la lógica de presentación.

El backend se plantea de forma conceptual utilizando MVC y una arquitectura por capas.
